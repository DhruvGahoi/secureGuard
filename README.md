## 🚀 Overview

**SecureGuard** is a comprehensive Data Loss Prevention (DLP) dashboard designed to monitor, detect, and prevent unauthorized data transmission within an organization. This application provides security analysts with real-time insights into user activities, policy violations, and potential insider threats.

This project was built as an assignment submission, focusing on clean architecture, component reusability, and responsive design.

### 🔗 Live Deployment
**[View Live Demo](https://secure-guard-xi.vercel.app)**

---

## ✨ Key Features

* **Real-time Threat Monitoring**: Interactive dashboard visualizing recent security alerts and data exfiltration attempts.
* **User Risk Profiling**: Detailed user behavior analytics to identify high-risk individuals based on activity anomalies.
* **Policy Management**: Interface to view and filter active security policies (e.g., USB usage, Cloud Uploads).
* **Responsive UI**: Optimized for varied screen sizes using modern CSS practices.

## 🛠️ Tech Stack

* **Frontend Framework**: React 18 (via Vite)
* **Language**: TypeScript
* **Styling**: Mantine
* **State Management**: React Context API / Hooks
* **Routing**: React Router DOM
* **Linting/Formatting**: ESLint, Prettier

## ⚙️ Setup & Installation

Follow these steps to set up the project locally:

```bash
    git clone [https://github.com/DhruvGahoi/secureGuard.git](https://github.com/DhruvGahoi/secureGuard.git)
    cd secureGuard
    npm install
    npm run dev
```
The application will be available at http://localhost:5173
